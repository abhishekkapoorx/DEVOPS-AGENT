# DevOps Agent CLI

The CLI is the fastest path from a noisy terminal to a traceable answer. It keeps local tool execution explicit, authenticated, and visible while the server stores durable conversation state.

Use the CLI when you want to inspect a workspace, ask an operational question, or approve a local read-only tool request.

## Start here

1. Install the CLI from the repository environment.
2. Sign in using the browser approval flow.
3. Start a conversation and keep the returned evidence in the session.

See `Authentication` for the sign-in flow.
